# 문서 정리 → 노션 복붙

팀 노션은 Claude와 연결되어 있지 않다. 결과물은 사용자가 **복사해서 노션에 붙여넣는다.**
그래서 이 Skill의 목표는 두 가지다.

1. 양식에 맞게 빠짐없이 정리한다.
2. 노션에 붙여넣었을 때 **형식이 그대로 유지되는** 마크다운만 쓴다.

## 진행 순서

### 1단계: 유형 고르기

사용자의 첫 메시지만으로 유형이 분명하면(예: 회의 녹취록을 주며 "회의록 정리") 추정한 유형을 한 줄로 확인만 받는다.
분명하지 않으면 아래 메뉴를 그대로 보여주고 번호로 답하게 한다.

```
어떤 자료를 정리할까요? 번호로 답해주세요.

1. 특허      (1-1 특허 초안 / 1-2 선행특허 조사)
2. 논문      (2-1 논문 작성 / 2-2 논문 리뷰)
3. 개발 문서
4. 시험일지
5. 회의록
6. 구매물품
7. 할 일
```

- 1·2번을 고르면 세부 유형을 묻는다(이미 "1-2"처럼 답했으면 묻지 않는다).
- 7번은 할 일 양식(`templates/todo.md`)의 순서대로 **분류를 체크박스로 고르게** 한다.
- 질문 도구(AskUserQuestion 등)가 있으면 2개 중 고르기·체크박스 고르기에 쓴다. 선택지는 질문당 4개까지라서
  7개 유형 메뉴는 위 텍스트 메뉴로 보여준다. 질문 도구가 없으면 모두 번호 목록으로 묻는다.

### 2단계: 양식 읽기

고른 유형의 양식 파일 **하나만** 읽는다. 다른 양식은 읽지 않는다(양식이 섞이는 것을 막기 위해).

| 번호 | 유형 | 양식 파일 |
|---|---|---|
| 1-1 | 특허 초안 | `templates/patent-draft.md` |
| 1-2 | 선행특허 조사 | `templates/patent-prior-art.md` |
| 2-1 | 논문 작성 | `templates/paper-writing.md` |
| 2-2 | 논문 리뷰 | `templates/paper-review.md` |
| 3 | 개발 문서 | `templates/dev-doc.md` |
| 4 | 시험일지 | `templates/test-log.md` |
| 5 | 회의록 | `templates/meeting.md` |
| 6 | 구매물품 | `templates/purchase.md` |
| 7 | 할 일 | `templates/todo.md` → 고른 분류의 `templates/todo/*.md` |

양식 파일은 네 부분으로 되어 있다: **① 노션 DB 속성 / ② 질문 목록 / ③ 본문 뼈대 / ④ 작성 메모.**

### 3단계: 자료 확인

이렇게 묻는다.

> 정리할 자료가 있으면 붙여넣거나 첨부해주세요(메모, 녹취록, PDF, 사진 설명, 엑셀 복사본 등 무엇이든).
> 자료가 없으면 "없음"이라고 답해주세요. 질문하면서 같이 채우겠습니다.

**자료 모드** (자료가 있을 때)
1. 자료를 읽고 ③ 본문 뼈대를 채워 초안을 만든다.
2. 자료에 없는 값은 지어내지 않고 `⚠️ 확인 필요`로 남긴다.
3. ② 질문 목록의 **필수** 항목 중 비어 있는 것만 **한 번에 모아** 묻는다(최대 5개). 선택 항목은 묻지 않는다.
4. 답을 반영해 4단계로 간다. 사용자가 "그냥 출력"이라고 하면 `⚠️ 확인 필요`를 남긴 채 출력한다.

**질문 모드** (자료가 없을 때)
1. ② 질문 목록을 단계 순서대로, **한 번에 2~4개씩** 묻는다.
2. 답이 "없음" "건너뛰기" "모름"이면 선택 항목은 섹션째 빼고, 필수 항목은 `⚠️ 확인 필요`로 둔다.
3. 답이 짧고 메모 같아도 그대로 받는다. 문장은 출력할 때 다듬는다.
4. 모든 단계가 끝나면 4단계로 간다.

### 4단계: 출력

아래 "출력 형식"대로 출력한다. 출력 전에 아래 "노션 복붙 규칙"을 지켰는지 스스로 확인한다.

### 5단계: 검사 (코드 실행이 가능한 환경)

본문을 파일로 저장했다면 검사 스크립트를 실행한다.

```bash
python3 <이 Skill 폴더>/scripts/check_notion_md.py <저장한 파일>
```

위반이 나오면 고쳐서 파일을 다시 저장하고, 다시 검사한다. 위반 0건이 될 때까지 반복한 뒤 사용자에게 보여준다.

### 6단계: 수정

사용자가 고칠 곳을 말하면 반영하고 **전체를 다시** 출력한다(부분만 출력하면 복붙할 때 헷갈린다).

## 출력 형식

### 페이지 유형 (구매물품을 뺀 모든 유형)

반드시 이 순서와 모양으로 출력한다.

1. **노션 속성 입력값** — 마크다운 표(`| 속성 | 값 |`). 사용자가 노션 DB의 속성 칸에 직접 입력한다.
   ① 노션 DB 속성 표에 있는 속성을 모두, 같은 순서로 쓴다. 값이 없으면 `⚠️ 확인 필요`.
2. **본문** — 백틱 **4개**로 감싼 `markdown` 코드 블록. 본문 안에 코드 블록이 있어도 깨지지 않게 하기 위해서다.
3. **확인 필요 목록** — `⚠️ 확인 필요`가 남아 있으면 무엇이 비었는지 한 줄씩. 없으면 생략.

출력 예시(모양만 참고):

`````
**① 노션 속성 입력값** — DB 속성 칸에 직접 입력

| 속성 | 값 |
|---|---|
| 시험명 | ... |

**② 본문** — 코드 블록 오른쪽 위 복사 버튼 → 노션 페이지 본문에 붙여넣기

````markdown
# 시험내용

- ...
````
`````

### 표 유형 (구매물품)

1. 마크다운 표로 보여준다(열 순서는 양식 그대로). claude.ai에서는 표를 드래그해 복사하면 엑셀·노션에 셀 단위로 붙여넣어진다.
2. 총 금액 계산식을 표 아래에 품목별로 한 줄씩 보여준다.

### 파일 저장 (Claude Code 등 파일을 쓸 수 있는 환경)

터미널 화면을 복사하면 긴 줄이 잘리거나 마크다운 기호가 사라질 수 있다. 그래서 파일로도 저장한다.

- 위치: 현재 작업 폴더의 `notion-output/` (없으면 만든다)
- 파일명: `YYYY-MM-DD_유형_제목.md` (날짜는 `date +%F`로 확인. 제목의 공백은 `_`, `/`는 `-`로)
- 페이지 유형: 파일에는 **본문만** 넣는다(속성 표와 바깥 코드 블록 제외). 속성 값은 화면에만 보여준다.
- 구매물품: `YYYY-MM-DD_구매물품.csv`를 **UTF-8 BOM**으로 저장한다(엑셀 한글 깨짐 방지). 노션 DB의 "CSV로 병합"에도 쓸 수 있다.
- 저장 후 클립보드 복사를 시도한다: `xclip -selection clipboard`, `wl-copy`, `pbcopy` 중 있는 것. 성공하면 "클립보드에 복사됨, 노션에 바로 붙여넣기" 라고 알린다. 없으면 파일 경로만 알린다.

## 노션 복붙 규칙

노션은 붙여넣은 일반 텍스트의 마크다운을 블록으로 바꾼다. 하지만 바꾸지 못하는 문법이 있다.
본문에는 **"쓴다" 칸의 문법만** 쓴다. "쓴다" 칸은 팀 노션에 실제로 붙여넣어 확인했다(2026-11-27, `tests/notion-paste-test.md`).

| 쓴다 | 쓰지 않는다 (이유) |
|---|---|
| 제목 `#` `##` `###` | `####` 이하 (노션 붙여넣기에서 제목으로 안 바뀜) |
| 목록 `-`, 번호 목록 `1.` | HTML 태그 `<br>` `<details>` `<!-- -->` (글자 그대로 남음) |
| 들여쓰기 목록 — **공백 4칸**씩 | 탭 문자 |
| 체크박스 `- [ ]` `- [x]` | 콜아웃, 토글, `> [!NOTE]` (변환 안 됨) |
| 표 (헤더 + `\|---\|` 구분 행) | 표 칸 안 줄바꿈, 칸 안 `\|` (`/`로 바꿔 쓴다) |
| 코드 블록 (언어 지정), 인용 `>`, 구분선 `---` | 수식 블록 `$$` (수식은 인라인 코드로) |
| Mermaid 코드 블록 ```` ```mermaid ```` (노션에서 다이어그램으로 보임) | |
| `**굵게**`, `*기울임*`, `` `인라인 코드` ``, `[글](URL)` | 이미지 문법 `![](...)`, 각주 `[^1]` |

추가 규칙
- 제목·표·코드 블록 앞뒤에는 **빈 줄**을 둔다.
- 그림 자리: `📷 [그림: 무엇을 보여주는 그림인지 — 노션에서 직접 첨부]`
- 첨부 파일 자리: `📎 [파일: 파일명 — 노션에서 직접 첨부]`
- 영상 자리: `🎞 [영상: 설명 — 노션에서 직접 첨부]`
- 노션에서 내보낸 자료에 있는 `!image.png` 같은 줄은 위의 그림 자리 표시로 바꾼다.
- 양식의 `{채울 내용}` `%% 안내 %%` 표시는 출력에 남기지 않는다.

## 작성 원칙

- **지어내지 않는다.** 번호(특허번호·출원번호·도면부호), 금액, 날짜, 수치, 단위, 고유명사, 링크는 받은 그대로 쓴다. 모르면 `⚠️ 확인 필요`.
- 사용자가 쓴 용어를 바꾸지 않는다(예: 사용자가 "쇼바"라고 쓰면 "쇼바"). 문장만 다듬는다.
- 문체는 개조식(명사형·짧은 문장)으로 쓴다. 단, 특허 초안의 서술 부분은 "~한다/~이다" 문장으로 쓴다.
- Claude가 내용을 **제안**하는 경우(특허 청구항 초안, 할 일 세부 작업 쪼개기 등)는 양식에 정해진 표시를 붙인다.
- 양식에 없는 섹션을 마음대로 추가하지 않는다. 자료에 양식 밖 중요한 내용이 있으면 가장 가까운 섹션에 넣고, 마땅한 곳이 없으면 출력 뒤에 "양식 밖 내용"으로 따로 알려준다.
