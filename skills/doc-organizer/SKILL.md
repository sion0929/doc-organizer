# 문서 정리 → 노션 복붙

팀 노션은 Claude와 연결되어 있지 않다. 결과물은 사용자가 **복사해서 노션에 붙여넣는다.**
이 Skill의 목표는 세 가지다.

1. 양식에 맞게 빠짐없이 정리한다.
2. 노션에 붙여넣었을 때 **형식이 그대로 유지되는** 마크다운만 쓴다.
3. 사용자는 바쁘다. **질문 왕복을 최소로** 한다.

## 진행 순서

### 1단계: 유형 고르기

첫 메시지만으로 유형이 분명하면(예: 녹취록과 함께 "회의록 정리") **따로 확인을 받지 않는다.**
대신 Claude의 첫 응답 맨 위에 한 줄을 붙인다: `회의록(5)으로 정리합니다. 다르면 말씀해주세요.`

분명하지 않으면 아래 메뉴를 그대로 보여주고 번호로 답하게 한다.

```
어떤 자료를 정리할까요? 번호로 답해주세요.

1. 특허      (1-1 특허 초안 / 1-2 선행특허 조사)
2. 논문      (2-1 논문 작성 / 2-2 논문 리뷰)
3. 개발 문서
4. 시험일지
5. 회의록
6. 구매물품
7. 할 일
```

- 1·2번은 세부 유형을 묻는다(이미 "1-2"처럼 답했으면 묻지 않는다). 이 질문은 3단계 자료 확인 질문과 한 메시지로 묶는다.
- 7번은 할 일 양식(`templates/todo.md`)의 순서대로 **분류를 체크박스로 고르게** 한다. 이 메시지에 3단계 자료 확인도 함께 넣는다.
- 질문 도구(AskUserQuestion 등)가 있으면 2개 중 고르기·체크박스 고르기에 쓴다. 선택지는 질문당 4개까지라서
  7개 유형 메뉴는 위 텍스트 메뉴로 보여준다. 질문 도구가 없으면 모두 번호 목록으로 묻는다.

### 2단계: 양식 읽기

고른 유형의 양식 파일만 읽는다(할 일은 `todo.md` + 고른 분류 파일들). 다른 유형의 양식은 읽지 않는다.

| 번호 | 유형 | 양식 파일 |
|---|---|---|
| 1-1 | 특허 초안 | `templates/patent-draft.md` |
| 1-2 | 선행특허 조사 | `templates/patent-prior-art.md` |
| 2-1 | 논문 작성 | `templates/paper-writing.md` |
| 2-2 | 논문 리뷰 | `templates/paper-review.md` |
| 3 | 개발 문서 | `templates/dev-doc.md` |
| 4 | 시험일지 | `templates/test-log.md` |
| 5 | 회의록 | `templates/meeting.md` |
| 6 | 구매물품 | `templates/purchase.md` |
| 7 | 할 일 | `templates/todo.md` → 고른 분류의 `templates/todo/*.md` |

양식 파일은 네 부분으로 되어 있다: **① 노션 DB 속성 / ② 질문 목록 / ③ 본문 뼈대 / ④ 작성 메모.**
양식의 지시가 이 파일과 다르면 **양식을 따른다**(유형별 예외는 양식에 적혀 있다).

### 3단계: 자료 확인

첫 메시지에 자료가 이미 있거나 "자료 없음"이라고 했으면 **이 단계는 건너뛴다.** 아니면 이렇게 묻는다.

> 정리할 자료가 있으면 붙여넣거나 파일 경로를 알려주세요(메모, 녹취록, PDF, 엑셀 복사본 등 무엇이든).
> 없으면 "없음"이라고 답해주세요. 질문하면서 같이 채우겠습니다.

#### 자료 모드 (자료가 있을 때)

1. 자료를 읽고 ③ 본문 뼈대를 채워 초안을 만든다(아직 보여주지 않는다).
2. 질문은 **한 메시지에 한 번만**, 최대 5개. 넣을 것(우선순위 순):
   1. 비어 있는 **필수** 항목 (여러 항목이 기대는 것 먼저. 예: 특허의 구성요소 목록)
   2. 양식 ④가 "묻는다"고 한 것 (예: 구매 엑셀의 총 금액 불일치)
   - 5개를 넘는 나머지는 `⚠️ 확인 필요`로 두고 ③ 확인할 것에 적는다.
   - 제안값(Claude가 추정한 속성 값·제목 등)만을 위해 질문을 보내지 않는다. 제안값은 ③ 확인할 것에 적는다.
3. 물을 것이 **없으면 질문 없이 바로 출력**한다.
4. 질문 메시지 끝에 항상 붙인다: `바로 받으시려면 "그냥 출력"이라고 해주세요. 비어 있는 곳은 ⚠️ 확인 필요로 표시합니다.`

#### 질문 모드 (자료가 없을 때)

왕복 횟수를 줄이는 것이 우선이다. 보통 문서는 **3~4번 안에** 끝낸다.

- 한 메시지에 질문 **최대 4개**. ② 질문 목록의 단계 순서를 따르되, **단계를 넘어 묶어도 된다.**
- `선택: 발명자, 관련 과제, 마감일` 처럼 한 줄에 묶인 선택 항목은 질문 1개로 센다.
- 반복 항목(특허 구성요소, 서브시스템, 모듈 등)은 먼저 목록만 받고, 다음 메시지에서 **모든 항목의 하위 질문을 한 번에** 묻는다(항목마다 짧은 하위 목록).
- 선택 질문은 메시지 끝에 "(선택, 건너뛰어도 됨)"으로 모아 둔다.
- 답이 짧고 메모 같아도 그대로 받는다. 문장은 출력할 때 다듬는다.

#### 답 처리 (두 모드 공통)

- "없음" "건너뛰기" "모름" 또는 **대답하지 않은 질문**:
  - 선택 항목 → 본문에서 그 줄(또는 `%% 선택 %%` 블록)을 빼고, 속성 값은 `-`
  - 필수 항목 → `⚠️ 확인 필요`
  - 단, 양식이 따로 정한 경우(예: 특허 영문 명칭은 번역 제안, 청구항은 초안 제안)는 양식을 따른다.
- "나중에" → 선택 항목처럼 비워 두고 ③ 확인할 것에 "나중에 채울 것"으로 적는다.
- "아직 안 정함" "미정" → `미정`. 정해지지 않은 것이므로 `⚠️ 확인 필요`(정해졌지만 받지 못한 값)와 구분한다.
- 첫 메시지나 앞선 답에 이미 나온 내용은 다시 묻지 않고 채운다.

### 4단계: 출력

아래 "출력 형식"대로 만든다. 파일을 쓸 수 있는 환경(Claude Code 등)에서는 **이 순서**로 한다.

1. 파일 저장 ("파일 저장과 클립보드" 참고)
2. 검사: `python3 <이 Skill 폴더>/scripts/check_notion_md.py <저장한 .md 파일>`
   → 위반이 있으면 고쳐서 다시 저장하고 다시 검사. **위반 0건**이 될 때까지.
3. 클립보드 복사 (검사를 통과한 최종 파일로)
4. 화면에 출력

파일을 쓸 수 없는 환경(claude.ai 등)에서는 출력 전에 "노션 복붙 규칙"을 스스로 확인한다.

### 5단계: 수정

사용자가 고칠 곳을 말하면 반영하고 **전체를 다시** 출력한다(부분만 출력하면 복붙할 때 헷갈린다). 파일도 다시 저장·검사·복사한다.

## 값 쓰는 규칙

- **지어내지 않는다.** 번호(특허번호·출원번호·도면부호), 금액, 날짜, 수치, 단위, 고유명사, 링크는 받은 그대로 쓴다.
- `⚠️ 확인 필요`는 **필수 항목**이 비었을 때, 그리고 "있다"고 했지만 값을 받지 못했을 때만 쓴다.
  선택 항목이 비면 본문에서는 줄을 빼고, 속성 표에서는 `-`로 둔다.
- **제안값**(Claude가 자료에서 추정한 속성 값, 지어 붙인 제목, 번역 등): 속성 표·본문에는 **값만** 쓴다.
  `(제안)` 같은 꼬리표를 값에 붙이지 않는다(노션 선택 속성에 그대로 입력되면 이상한 선택지가 생긴다).
  대신 ③ 확인할 것에 `제안값: 속성 — 근거`로 적는다. 양식이 정한 표시(예: `(번역 제안)`, `(초안 — 변리사 검토 필요)`)는 예외로 쓴다.
- **날짜 속성**은 `YYYY-MM-DD`로 쓴다. 연도가 없으면 오늘(`date +%F`) 기준 올해로 채우고 ③에 "연도 추정"이라고 적는다.
  본문 안의 날짜·기한("11/27", "다음 주 수요일")은 들은 그대로 쓴다.
- **불확실한 내용**은 사용자가 쓴 확신 정도를 살려 "의심됨", "추정"처럼 쓴다. 본문에 그냥 "확인 필요"라는 말은 쓰지 않는다(`⚠️ 확인 필요` 표시와 헷갈린다).
- 사용자가 쓴 용어를 바꾸지 않는다(예: 사용자가 "쇼바"라고 쓰면 "쇼바"). 문장만 다듬는다.
- 문체는 개조식(명사형·짧은 문장). 단, 특허 초안의 서술 부분은 "…한다 / …이다" 문장(청구항은 특허 관례대로 명사로 끝남).
- 양식에 없는 섹션을 마음대로 추가하지 않는다. 양식 밖 중요한 내용은 가장 가까운 섹션에 넣고, 마땅한 곳이 없으면 ④ 따로 할 일에 "양식 밖 내용"으로 적는다.

## 출력 형식

### 페이지 유형 (구매물품을 뺀 모든 유형)

이 순서로 출력한다. ③ ④는 내용이 있을 때만.

1. **① 노션 속성 입력값** — 마크다운 표 `| 속성 | 값 |`. 양식 ① 표의 속성을 **모두, 같은 순서로**.
2. **② 본문** — 백틱 **4개**로 감싼 `markdown` 코드 블록(본문 안에 코드 블록이 있어도 깨지지 않게).
3. **③ 확인할 것** — 한 줄씩: `⚠️ 확인 필요`로 남은 항목, 제안값, 연도 추정, 나중에 채울 것.
4. **④ 따로 할 일** — 노션에서 직접 첨부할 그림·파일·영상 목록, 계산식, 양식 밖 내용 등 양식 ④가 출력 뒤에 보여주라고 한 것.

② 제목 줄은 환경에 맞게 쓴다.
- Claude Code: `**② 본문** — 클립보드에 복사됨 (파일: ~/notion-output/…) → 노션 페이지 본문에 Ctrl+V`
- claude.ai: `**② 본문** — 코드 블록 오른쪽 위 복사 버튼 → 노션 페이지 본문에 붙여넣기`

출력 예시(모양만 참고):

`````
시험일지(4)로 정리합니다. 다르면 말씀해주세요.

**① 노션 속성 입력값** — DB 속성 칸에 직접 입력

| 속성 | 값 |
|---|---|
| 시험명 | ... |
| 관련 과제 | - |

**② 본문** — 클립보드에 복사됨 (파일: ~/notion-output/2026-11-20_시험일지_로버_주행.md) → 노션 페이지 본문에 Ctrl+V

````markdown
# 시험내용

- ...
````

**③ 확인할 것**
- 제안값: 결과 — 회전 구간 이탈이 있어 "부분 성공"
- 시험일 — 연도 추정 (2026)

**④ 따로 할 일**
- 노션에서 직접 첨부: rover_1120.bag, 사진 2장
`````

### 표 유형 (구매물품)

1. ① ② 대신 마크다운 표 하나(열 순서는 양식 그대로). 코드 블록으로 감싸지 않는다.
2. ③ 확인할 것, ④ 따로 할 일(계산식 등)은 페이지 유형과 같다.

## 파일 저장과 클립보드

터미널 화면을 복사하면 긴 줄이 잘리거나 마크다운 기호가 사라질 수 있다. 그래서 파일로 저장하고 클립보드에 복사한다.

- 위치: **`~/notion-output/`** (없으면 만든다). 작업 폴더와 상관없이 항상 여기.
- 파일명: `{날짜}_{유형}_{제목}.md`
  - 날짜: 문서의 날짜(시험일·회의 일시 등)가 있으면 그 날짜, 없으면 오늘. `YYYY-MM-DD`.
  - 유형: 2단계 표의 유형 이름에서 공백을 `_`로 (예: `특허_초안`, `시험일지`, `할_일`).
  - 제목: 제목 속성 값에서 날짜 부분을 빼고, 한글·영문·숫자 외의 글자는 `_`로 바꾸고, `_`가 겹치면 하나로, 30자 이내. 제목이 없으면 `제목미정`.
  - 같은 이름의 파일이 있으면 끝에 `_2`, `_3`.
- 페이지 유형: 파일에는 **본문만** 넣는다(속성 표, 바깥 ```` 블록, ③ ④ 제외).
- 구매물품: `.md` 대신 `.csv`(UTF-8 BOM, 형식은 `purchase.md`). 검사기는 돌리지 않는다.
- 클립보드: `xclip -selection clipboard`, `wl-copy`, `pbcopy` 중 있는 것.
  - 페이지 유형: 저장한 `.md` 파일 내용 → 노션 본문에 그대로 붙여넣기
  - 구매물품: 표를 **탭으로 구분한 글자**(머리글 포함, ₩·쉼표 포함 표와 같은 값)로 복사 → 엑셀에 붙이면 칸별로 나뉜다.
  - 복사 도구가 없으면 파일 경로만 알린다.

## 노션 복붙 규칙

노션은 붙여넣은 일반 텍스트의 마크다운을 블록으로 바꾼다. 하지만 바꾸지 못하는 문법이 있다.
본문에는 **"쓴다" 칸의 문법만** 쓴다. "쓴다" 칸은 팀 노션에 실제로 붙여넣어 확인했다
(2026-11-27, 저장소의 `tests/notion-paste-test.md`).

| 쓴다 | 쓰지 않는다 (이유) |
|---|---|
| 제목 `#` `##` `###` | `####` 이하 (노션 붙여넣기에서 제목으로 안 바뀜) |
| 목록 `-`, 번호 목록 `1.` | HTML 태그 `<br>` `<details>` `<!-- -->` (글자 그대로 남음) |
| 들여쓰기 목록 — **공백 4칸**씩 | 탭 문자 |
| 체크박스 `- [ ]` `- [x]` | 콜아웃, 토글, `> [!NOTE]` (변환 안 됨) |
| 표 (헤더 + `\|---\|` 구분 행) | 표 칸 안 줄바꿈, 칸 안 `\|` (`/`로 바꿔 쓴다) |
| 코드 블록 (언어 지정), 인용 `>`, 구분선 `---` | 수식 블록 `$$` (수식은 인라인 코드로) |
| Mermaid 코드 블록 ```` ```mermaid ```` (노션에서 다이어그램으로 보임) | 이미지 문법 `![](...)`, 각주 `[^1]` |
| `**굵게**`, `*기울임*`, `` `인라인 코드` ``, `[글](URL)` | 한 줄에 `~` 두 개 (취소선으로 바뀔 수 있음 → 범위는 `–`) |

추가 규칙
- 제목·표·코드 블록 앞에는 **빈 줄**, 제목·표 다음에도 **빈 줄**.
- 그림 자리: `📷 [그림: 무엇을 보여주는 그림인지 — 노션에서 직접 첨부]`
- 첨부 파일 자리: `📎 [파일: 파일명 — 노션에서 직접 첨부]`
- 영상 자리: `🎞 [영상: 설명 — 노션에서 직접 첨부]`
- 노션에서 내보낸 자료에 있는 `!image.png` 같은 줄은 위의 그림 자리 표시로 바꾼다.
- 양식의 `{채울 내용}` `%% 안내 %%` 표시는 출력에 남기지 않는다.
