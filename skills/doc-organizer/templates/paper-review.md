# 논문 리뷰 양식

- 유형: 2-2. 논문 리뷰
- 출력: 페이지 (논문 1편 = 페이지 1개)
- 제목 수준: 섹션 `###`
- 용도: 남의 논문을 읽고 핵심 내용과 우리 연구와의 관련성을 정리한 기록. 우리가 쓰는 논문의 개요인 "논문 작성"(2-1)과 다르다.

## ① 노션 DB 속성

| 속성 | 종류 | 선택지 / 비고 |
|---|---|---|
| 논문 제목 | 제목 | 원문 제목 그대로 (번역하지 않는다) |
| 저자 | 텍스트 | 원문 표기 그대로. 저자 순서대로, 쉼표로 구분 |
| 게재처 | 선택 | 학회·저널 이름 |
| 연도 | 숫자 | 게재 연도 |
| 링크/DOI | URL | DOI 또는 원문 링크. 받은 그대로 |
| 분야 태그 | 다중 선택 | 연구 분야 키워드 |
| 관련도 | 선택 | 상 / 중 / 하 |
| 리뷰어 | 사람 | 노션에서 직접 선택. 출력에는 이름만 적는다 |
| 리뷰일 | 날짜 | |

## ② 질문 목록

질문 모드에서는 단계 순서대로 한 번에 2~4개씩 묻는다. 자료 모드에서는 비어 있는 **필수**만 묻는다.

### 1단계: 기본 정보
- **필수** 논문 제목 (원문 그대로)
- 선택: 저자, 게재처, 연도, 링크/DOI, 분야 태그, 리뷰어, 리뷰일

### 2단계: 문제와 방법
- **필수** 이 논문이 풀려는 문제는?
- **필수** 제안 방법의 핵심은? (핵심 아이디어·모듈마다)
- 선택: 핵심 그림(전체 구조도 등)이 있나요? 무엇을 보여주나요?

### 3단계: 실험
- **필수** 실험 환경·데이터, 비교 대상, 평가 지표는?
- **필수** 주요 결과는? (수치가 있으면 방법별·지표별로)

### 4단계: 기여점과 한계
- **필수** 이 논문의 기여점은?
- 선택: 한계는? (논문이 밝힌 것과 리뷰어가 본 것을 구분해서)

### 5단계: 우리 연구와의 관련성
- **필수** 우리 연구에 활용할 점은? 우리 연구와 다른 점은?
- 선택: 인용할 문장과 쪽수는?
- 선택: 더 읽어볼 레퍼런스는?
- 관련성을 듣고 관련도(상/중/하) 속성 값을 Claude가 채우고 ③ 확인할 것에 제안값으로 적는다(이것만을 위해 묻지 않는다).

## ③ 본문 뼈대

- `{ }` 는 채울 자리. 출력에서는 내용으로 바꾸거나 `➕ 추가 권장` 로 둔다.
- `%% 반복: … %%` 아래 블록은 개수만큼 반복, `%% 선택: … %%` 아래 블록은 내용이 없으면 통째로 뺀다.
- `%% … %%` 줄 자체는 출력하지 않는다.

````markdown
### 한 줄 요약

{이 논문이 무엇을 어떻게 해서 무엇을 보였는지 한 줄}

### 문제 정의

- {이 논문이 풀려는 문제}
    - {문제 환경 / 가정 / 입력과 출력}

### 제안 방법

📷 [그림: {핵심 그림 — 무엇을 보여주는지} — 노션에서 직접 첨부]

%% 반복: 핵심 아이디어(모듈)마다 %%
- {핵심 아이디어 / 모듈 이름}
    - {설명}

### 실험

- 환경·데이터: {실험 환경 / 데이터셋}
- 비교 대상: {비교한 방법}
- 지표: {평가 지표}

**주요 결과**

%% 선택: 결과 수치가 있을 때 — 행은 방법마다, 열은 지표마다 늘린다 %%
| 방법 | {지표} | {지표} |
|---|---|---|
| {방법 이름} | {수치} | {수치} |

%% 반복: 결과에서 읽은 점마다 %%
- {주요 결과: 어떤 조건에서 무엇이 얼마나 나았는지}

### 기여점

%% 반복: 기여점마다 %%
- {기여점}

%% 선택: 한계가 있을 때 %%
### 한계

%% 반복: 한계마다 %%
- {한계} ({논문이 밝힘 / 리뷰어 의견})

### 우리 연구와의 관련성

**활용할 점**

- {우리 연구에 가져다 쓸 수 있는 아이디어 / 방법 / 데이터}

**차이점**

- {우리 연구와 다른 점: 문제 설정 / 방법 / 환경}

%% 선택: 인용할 문장이 있을 때 %%
**인용할 부분**

%% 반복: 인용할 문장마다 %%
> {원문 문장 그대로} (p. {쪽 번호})

%% 선택: 더 읽어볼 논문이 있을 때 %%
### 더 읽어볼 레퍼런스

%% 반복: 논문마다 %%
- {논문 제목} ({저자}, {연도})
    - {읽어볼 이유}
````

## ④ 작성 메모

- 자료는 보통 논문 PDF다. 초록·서론·방법·실험·결론에서 내용을 뽑는다. 우리 연구와의 관련성은 논문에서 알 수 없으므로 자료 모드에서도 사용자에게 묻는다(Claude가 짐작해 채우지 않는다).
- 한 줄 요약은 문제 정의·제안 방법·주요 결과에서 뽑아 Claude가 쓴다. 사용자가 준 요약이 있으면 그것을 쓴다.
- 논문 제목·저자·방법 이름·데이터셋·지표 이름은 원문 표기 그대로 쓴다(번역하지 않는다). 설명은 한국어 개조식으로 쓴다.
- 결과 수치는 원문 그대로 쓴다(단위·소수점 자리 포함). 논문에 없는 수치를 계산해 넣지 않는다. 원문 표에서 일부 행·열만 옮겼으면 표 아래 목록에 "원문 표 일부"라고 적는다.
- 표 칸 안에서 줄을 바꾸지 않고, 칸 안의 `|` 는 `/` 로 바꿔 쓴다.
- 수식은 인라인 코드로 쓴다. `$$` 수식 블록은 쓰지 않는다.
- 한계는 논문이 직접 밝힌 것과 리뷰어 의견을 괄호 표시로 구분한다.
- 인용할 부분
    - 원문 문장을 `>` 로 한 글자도 바꾸지 않고 인용한다. 인용 안에서 요약·의역·번역하지 않는다.
    - 문장 뒤에 `(p. 쪽 번호)` 를 붙인다. 논문에 인쇄된 쪽 번호를 우선 쓰고, 없으면 PDF 쪽 번호를 쓴다. 모르면 `(p. ➕ 추가 권장)`.
    - 원문을 확인할 수 없는 문장은 인용으로 쓰지 않고 `➕ 추가 권장` 로 남긴다.
- 더 읽어볼 레퍼런스의 제목·저자·연도는 논문 참고문헌 목록에 적힌 그대로 쓴다. 링크를 받았으면 제목에 `[제목](URL)` 으로 건다.
- 📷 줄은 사용자가 그림이 없다고 하면 뺀다. 있는지 모르면 남겨 둔다(노션에서 첨부할 자리). ④ 따로 할 일에 "노션에서 직접 첨부할 그림" 목록을 보여준다.
