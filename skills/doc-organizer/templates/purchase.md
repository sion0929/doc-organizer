# 구매물품 양식

- 유형: 6. 구매물품
- 출력: 표 (품목 1개 = 1행, 페이지 본문 없음) + Claude Code에서는 CSV 파일
- 제목 수준: 없음 (표만 출력)
- 용도: 구매 요청·진행 관리. 품목 여러 개를 한 번에 받아 엑셀·노션 DB에 붙여넣을 표로 만든다. 표의 열이 곧 노션 DB 속성이다.

## ① 노션 DB 속성

열 이름과 순서는 구매 엑셀의 열 순서 그대로다.

| 속성 | 종류 | 선택지 / 비고 |
|---|---|---|
| 할당 과제 | 선택 | 과제명 |
| 품목 | 제목 | 품목 이름 (사용자가 쓴 이름 그대로) |
| 수량 | 숫자 | 숫자만 |
| 단가 | 숫자 | 숫자 형식 "원"(₩) |
| 배송비 | 숫자 | 숫자 형식 "원"(₩). 받지 못하면 0 |
| 총 금액 | 숫자 | = 수량 × 단가 + 배송비. 노션에서는 수식 속성 `prop("수량") * prop("단가") + prop("배송비")` 를 권장한다. 단, CSV로 가져올 때는 숫자 속성으로 들어간다(가져온 뒤 속성 종류를 수식으로 바꾸고 위 식을 넣을 수 있다) |
| 세부사항 (옵션) | 텍스트 | 색상, 규격, 선택 옵션 등 |
| 용도 | 텍스트 | |
| 구매 링크 | URL | 받은 주소 그대로 |
| 진행 상태 | 선택 | 구매 요청 / 구매 진행 / 구매 완료 / 품절 / 취소 |

## ② 질문 목록

질문 모드에서는 단계 순서대로 한 번에 2~4개씩 묻는다. 자료 모드에서는 비어 있는 **필수**만 묻는다.
품목은 여러 개를 한 번에 받는다(한 줄에 품목 하나씩).

자료 모드: 엑셀에서 복사한 행(탭으로 구분), 장바구니 화면 글, 견적서, 링크 목록 등을 받는다. 자료에 있는 값만 표에 옮긴다.
가격은 링크에서 추측하지 않고, 링크를 열어 가져오지도 않는다. 단가가 없으면 묻는다.
엑셀 행에 머리글이 있으면 머리글 이름으로 열을 맞추고, 머리글이 없으면 양식의 열 순서로 보고 한 줄로 확인받는다.

### 1단계: 품목과 가격
- **필수** 살 품목들은? 품목마다 한 줄에 이름, 수량, 단가
- 선택: 품목별 배송비 (받지 못하면 ₩0으로 계산하고 그렇게 했다고 알린다)
- 선택: 세부사항 (옵션) — 색상, 규격, 선택 옵션 등

### 2단계: 과제와 용도
- **필수** 할당 과제는? (모든 품목이 같으면 한 번만)
- 선택: 품목별 용도

### 3단계: 링크와 진행 상태
- 선택: 구매 링크 (받은 주소 그대로)
- 선택: 진행 상태 — 구매 요청 / 구매 진행 / 구매 완료 / 품절 / 취소 (정해지지 않았으면 `구매 요청`)

## ③ 본문 뼈대

구매물품은 페이지 본문 없이 **표 하나**로 출력한다(품목 1개 = 1행).

- `{ }` 는 채울 자리. 출력에서는 내용으로 바꾸거나 `➕ 추가 권장` 로 둔다.
- 표 안에는 `%% … %%` 줄을 넣을 수 없다. 그래서 `{ }` 행 하나를 **품목마다 한 행씩 반복**한다(반복: 품목마다).
- 열 이름과 순서는 바꾸지 않는다. 값이 없는 열도 빼지 않는다.
- 출력할 때는 표를 코드 블록으로 감싸지 않고 마크다운 표 그대로 보여준다(드래그해 복사하면 엑셀·노션에 셀 단위로 붙여넣어진다). 아래 코드 블록은 양식을 보여주기 위한 것이다.

````markdown
| 할당 과제 | 품목 | 수량 | 단가 | 배송비 | 총 금액 | 세부사항 (옵션) | 용도 | 구매 링크 | 진행 상태 |
|---|---|---|---|---|---|---|---|---|---|
| {과제명} | {품목 이름} | {수량} | ₩{단가} | ₩{배송비} | ₩{총 금액} | {색상 / 규격 / 옵션} | {용도} | {받은 URL 그대로} | {진행 상태} |
````

### 계산식 (표 아래)

④ 따로 할 일에 품목마다 한 줄씩 총 금액 계산식을 쓴다.

```
- {품목}: {수량} × ₩{단가} + ₩{배송비} = ₩{총 금액}
```

이어서 해당하는 것만 한 줄씩 알린다.

- 배송비를 받지 못해 ₩0으로 계산한 품목: {품목, …}
- 진행 상태를 받지 못해 `구매 요청`으로 둔 품목: {품목, …}
- ➕ 추가 권장가 남은 칸: {품목 — 열 이름}

### CSV 형식

파일을 쓸 수 있는 환경(Claude Code 등)에서는 표와 같은 내용을 CSV로도 저장한다. 엑셀로 열거나 노션 DB의 "CSV로 병합"에 쓴다.

- 파일: `~/notion-output/{날짜}_구매물품_{첫 품목}.csv` (날짜는 `date +%F`, 품목이 여러 개면 `{첫 품목}_외N`. 같은 이름이 있으면 `_2`)
- 인코딩: **UTF-8 BOM** (엑셀에서 한글이 깨지지 않게). Python이면 `open(경로, "w", encoding="utf-8-sig", newline="")` + `csv.writer`.
- 첫 줄은 열 이름. 표와 같은 10개 열, 같은 순서.
- 숫자 열(수량, 단가, 배송비, 총 금액)은 **숫자만** 쓴다. `₩`, 쉼표, 단위를 붙이지 않는다(예: `1234000`). 그래야 노션 숫자 속성으로 그대로 들어간다.
- 값이 없는 숫자 칸은 빈 칸으로 둔다(글자가 들어가면 숫자로 안 들어간다). 값이 없는 글자 칸은 필수(할당 과제, 품목)면 `➕ 추가 권장`, 선택(세부사항, 용도, 구매 링크)이면 빈 칸.
- 구매 링크는 받은 URL 그대로 쓴다.
- 표에서 `|` 를 `/` 로 바꾼 칸도 CSV에는 원래 글자 그대로 쓴다. 쉼표·큰따옴표·줄바꿈이 들어간 값은 큰따옴표로 감싼다(`csv.writer` 가 알아서 처리).
- 할당 과제와 진행 상태는 노션 선택지와 글자(띄어쓰기 포함)가 같아야 같은 선택지로 묶인다.
- 파일을 쓸 수 없는 환경(claude.ai)에서는 CSV를 만들지 않는다. 사용자가 원하면 같은 형식을 `csv` 코드 블록으로 보여준다.

```csv
할당 과제,품목,수량,단가,배송비,총 금액,세부사항 (옵션),용도,구매 링크,진행 상태
{과제명},{품목 이름},{수량},{단가},{배송비},{총 금액},{옵션},{용도},{URL},{진행 상태}
```

## ④ 작성 메모

- 표의 금액(단가, 배송비, 총 금액)은 `₩1,234,000` 처럼 ₩ + 세 자리 쉼표로 쓴다. 받은 금액의 숫자는 바꾸지 않고 형식만 맞춘다.
- 표에서도 선택 열(세부사항 (옵션), 용도, 구매 링크)이 비면 칸을 비워 둔다. `➕ 추가 권장` 는 필수 열(할당 과제, 품목, 수량, 단가)에만 쓴다. 사용자가 "나중에"라고 한 칸도 비워 두고 ③ 확인할 것에 적는다.
- 총 금액 = 수량 × 단가 + 배송비. 수량이나 단가가 없으면 총 금액도 `➕ 추가 권장` 로 두고, 계산식 줄에도 그렇게 표시한다.
- 배송비를 받지 못한 품목은 `₩0` 으로 계산하고 계산식 아래에 알린다. 사용자가 배송비가 주문 전체에 한 번 붙는다고 말한 경우에만 어느 행에 넣을지 묻는다(같은 판매처인지 링크로 추측하지 않는다). 품목별로 나눠 넣지 않는다.
- 견적서에 공급가액과 부가세가 나뉘어 있으면 단가를 부가세 포함으로 할지 별도로 할지 묻는다. 임의로 더하거나 빼지 않는다.
- 외화 가격은 원화로 환산하지 않는다. 원화 금액을 묻는다.
- 엑셀에서 붙여넣은 행에 총 금액이 이미 있으면 다시 계산해 비교한다. 다르면 고치지 말고 두 값을 보여주고 묻는다. 사용자가 "그냥 출력"하면 표·CSV에는 받은 값을 그대로 두고, 계산식 줄에 `≠ 받은 값 ₩{받은 값}` 을 붙이고 ③ 확인할 것에 적는다.
- 수량은 숫자만 쓴다. 단위가 붙어 있으면(예: 2박스) 숫자는 수량에, 단위는 세부사항 (옵션)에 적는다.
- 링크만 받은 품목은 품목 이름이나 가격을 링크에서 추측하지 않는다. 주소에 상품명이 보여도 사용자에게 확인한다. 단가가 빠진 품목이 여러 개면 품목 이름을 나열해 한 질문으로 묶어 묻는다.
- 구매 링크는 받은 URL을 그대로 쓴다. 줄이지 않고, `?` 뒤 파라미터도 지우지 않고, `[글](URL)` 링크로 바꾸지 않는다(엑셀에 붙여넣을 때 주소가 그대로 들어가게).
- 표 칸 안의 `|` 는 `/` 로 바꾼다. 칸 안에서 줄을 바꾸지 않는다.
- 진행 상태를 받지 못하면 `구매 요청` 으로 두고 그렇게 했다고 알린다. 선택지 다섯 개 밖의 말을 쓰면 가장 가까운 선택지로 채우고 ③ 확인할 것에 제안값으로 적는다.
