# 시험일지 양식

- 유형: 4. 시험일지
- 출력: 페이지
- 제목 수준: 섹션 `#`, 하위 항목 `###`
- 용도: 하루(한 번) 시험의 기록. 실험 전체를 종합하는 "실험 내용 정리"(할 일 분류)와 다르다.

## ① 노션 DB 속성

| 속성 | 종류 | 선택지 / 비고 |
|---|---|---|
| 시험명 | 제목 | 예: 날짜 + 시험 대상 + 시험 목적을 짧게 |
| 시험일 | 날짜 | |
| 장소 | 텍스트 | |
| 참여자 | 사람 | 노션에서 직접 선택. 출력에는 이름만 적는다 |
| 관련 과제 | 선택 | 과제명 |
| 시험 대상 시스템 | 다중 선택 | 시험한 서브시스템들 |
| 결과 | 선택 | 성공 / 부분 성공 / 실패 |

## ② 질문 목록

질문 모드에서는 단계 순서대로 한 번에 2~4개씩 묻는다. 자료 모드에서는 비어 있는 **필수**만 묻는다.

### 1단계: 기본 정보
- **필수** 시험명(또는 무엇을 시험했는지 한 줄)
- **필수** 시험일
- 선택: 장소, 참여자, 관련 과제

### 2단계: 시험내용
- **필수** 이번에 시험한 항목들은? (항목별로 한 줄씩)
- 선택: 항목별 세부 내용이나 지난번과 달라진 점은?

### 3단계: 시험결과
- **필수** 서브시스템(또는 시험 항목)별 결과는? 성공/실패, 관찰한 현상, 수치
- 선택: 서브시스템별 결론, 참고한 링크, 남겨둔 사진·영상
- 시험 대상 시스템과 결과(성공/부분 성공/실패) 속성은 결과를 보고 Claude가 채우고 ③ 확인할 것에 제안값으로 적는다(이것만을 위해 묻지 않는다).

### 4단계: 분석
- 선택: 문제의 원인으로 보이는 것, 로그·그래프에서 확인한 것은?

### 5단계: TODO
- 선택: 다음 시험 날짜와 계획은? 안 될 경우의 차선책은?

### 6단계: LOG
- 선택: 남긴 데이터 파일은? (rosbag, ulog, 영상 등 종류별 파일명)

## ③ 본문 뼈대

- `{ }` 는 채울 자리. 출력에서는 내용으로 바꾸거나 `⚠️ 확인 필요` 로 둔다.
- `%% 반복: … %%` 아래 블록은 개수만큼 반복, `%% 선택: … %%` 아래 블록은 내용이 없으면 통째로 뺀다.
- `%% … %%` 줄 자체는 출력하지 않는다.

````markdown
# 시험내용

%% 반복: 시험 항목마다 %%
- {시험 항목}
    - {세부 내용 / 지난번과 달라진 점}

# 시험결과

%% 반복: 서브시스템(시험 항목)마다 %%
### {서브시스템 이름}

- {결과 / 관찰한 현상 / 수치}
    - {세부 설명}
- 📷 [그림: {무엇을 보여주는지} — 노션에서 직접 첨부]
- 참고: [{링크 설명}]({URL})
- 결론: {이 서브시스템에 대한 한 줄 결론}

%% 선택: 분석할 내용이 있을 때 %%
# 분석

%% 반복: 발견 사항마다 %%
- {발견 사항}
    - {근거: 로그·그래프에서 확인한 것}
    - 📷 [그림: {그래프·로그 설명} — 노션에서 직접 첨부]

%% 선택: 다음 계획이 있을 때 %%
# TODO

{다음 시험 날짜} 실험 계획

- {할 일}
    - 안 될 경우: {차선책}

%% 선택: 남긴 데이터가 있을 때 %%
# LOG

%% 반복: 데이터 종류마다 %%
- {데이터 종류: rosbag / ulog / 영상 등}
    - 📎 [파일: {파일명} — 노션에서 직접 첨부]
````

## ④ 작성 메모

- 결과에 나온 수치·토픽 이름·파라미터·파일명은 받은 그대로 쓴다(대소문자, 밑줄 포함).
- 토픽·명령어·파일 경로는 인라인 코드(`` ` ``)로 감싼다.
- 시험결과의 "결론:" 줄은 사용자가 결론을 말했을 때만 쓴다. 결론이 없으면 그 줄을 뺀다(지어내지 않는다).
- 원인이 확실하지 않은 내용은 분석에 "의심됨" "추정"처럼 사용자가 쓴 확신 정도를 그대로 살린다.
- 사진·영상·로그 파일은 붙여넣기로 들어가지 않는다. 자리 표시만 남기고, ④ 따로 할 일에 "노션에서 직접 첨부할 파일" 목록을 보여준다.
- 사진이 어느 서브시스템 것인지 알면 그 서브시스템의 시험결과에, 모르면 LOG에 `- 사진` 항목으로 넣는다. 무엇을 찍었는지 모르면 `📷 [그림: 사진 1 — 노션에서 직접 첨부]` 처럼 번호만 붙인다.
