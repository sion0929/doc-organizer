# 선행특허 조사 양식

- 유형: 1-2. 선행특허 조사
- 출력: 페이지 (선행특허 1건 = 페이지 1개)
- 제목 수준: 섹션 `##`
- 용도: 이미 공개·등록된 특허 한 건을 읽고 요약한 뒤 우리 발명과 비교한 기록. 우리 발명을 출원하려고 쓰는 "특허 초안"(1-1)과 다르다.

## ① 노션 DB 속성

| 속성 | 종류 | 선택지 / 비고 |
|---|---|---|
| 발명 명칭 | 제목 | 선행특허의 발명 명칭. 원문 그대로 |
| 특허번호 | 텍스트 | 공개번호 또는 등록번호. 받은 그대로 |
| 출원인 | 텍스트 | 원문 표기 그대로 |
| 국가 | 선택 | KR / US / EP / JP / CN / WO / 기타 |
| 출원일 | 날짜 | |
| 공개·등록일 | 날짜 | 등록일이 있으면 등록일, 없으면 공개일 |
| 법적 상태 | 선택 | 공개 / 등록 / 거절 / 소멸 / 기타 |
| 관련도 | 선택 | 상 / 중 / 하 |
| 관련 우리 발명 | 관계형 | 특허 초안 DB와 연결. 출력에는 우리 발명 명칭만 적는다 |
| 링크 | URL | KIPRIS·Google Patents 등 원문 링크 |

## ② 질문 목록

질문 모드에서는 단계 순서대로 한 번에 2~4개씩 묻는다. 자료 모드에서는 비어 있는 **필수**만 묻는다.

### 1단계: 대상 특허
- **필수** 특허번호 (공개번호 또는 등록번호)
- **필수** 발명 명칭
- 선택: 출원인, 국가, 출원일, 공개·등록일, 법적 상태, 링크

### 2단계: 특허 내용
- **필수** 이 특허가 해결하려는 문제와 해결 방법은? (요약)
- **필수** 대표 청구항 원문 (보통 청구항 1). 고쳐 쓰지 말고 원문을 복사해 붙여넣어 주세요.
- 선택: 핵심 구성요소와 각각의 역할은? 대표 도면이 있나요?

### 3단계: 우리 발명과 비교
- **필수** 비교할 우리 발명은? (발명 명칭과 구성요소. 특허 초안 페이지를 붙여넣어도 된다)
- **필수** 구성요소별로 선행특허와 우리 발명의 같은 점·다른 점은? (두 발명 자료가 다 있으면 Claude가 먼저 표를 채우고 확인받는다)
- 비교를 마치면 관련도(상/중/하) 속성 값을 Claude가 채우고 ③ 확인할 것에 제안값으로 적는다(이것만을 위해 묻지 않는다).

### 4단계: 차별화·메모
- 선택: 차별화하거나 피해 가야 할 포인트로 생각한 것은? (없으면 비교 표의 "차이" 칸에서 정리한다)
- 선택: 메모 (검색어, 함께 볼 특허, 추가로 확인할 점 등)

## ③ 본문 뼈대

- `{ }` 는 채울 자리. 출력에서는 내용으로 바꾸거나 `➕ 추가 권장` 로 둔다.
- `%% 반복: … %%` 아래 블록은 개수만큼 반복, `%% 선택: … %%` 아래 블록은 내용이 없으면 통째로 뺀다.
- `%% … %%` 줄 자체는 출력하지 않는다.

````markdown
## 요약

{이 특허가 해결하려는 문제와 해결 방법을 2~3줄로}

## 대표 청구항

**청구항 {번호}**

> {청구항 원문 — 한 글자도 바꾸지 않고 그대로}

## 핵심 구성

📷 [그림: {대표 도면 — 무엇을 보여주는지} — 노션에서 직접 첨부]

%% 반복: 구성요소마다 %%
- **{구성요소}**: {역할 / 특징}

## 우리 발명과 비교

%% 반복: 표의 내용 행(셋째 줄)을 비교할 구성요소마다 %%
| 구성요소 | 선행특허 | 우리 발명 | 차이 |
|---|---|---|---|
| {구성요소} | {선행특허의 해당 구성} | {우리 발명의 해당 구성} | {같음 / 다름 — 다른 점 한 줄} |

## 차별화·회피 포인트

%% 반복: 포인트마다 %%
1. {우리 발명이 이 특허와 구별되는 점 또는 피해 가야 할 점}
    - 근거: {비교 표의 해당 구성요소}

%% 선택: 메모가 있을 때 %%
## 메모

- {검색어 / 함께 볼 특허 / 추가로 확인할 점 등}
````

## ④ 작성 메모

- 자료는 보통 KIPRIS·Google Patents 화면 복사본이나 특허 PDF다. 메뉴·버튼·광고 글자는 버리고 서지 정보(번호·출원인·날짜·상태), 요약, 청구범위, 도면 설명만 쓴다.
- 대표 청구항
    - 원문을 `>` 로 그대로 인용한다. 띄어쓰기·문장부호·기호·번호 표기까지 바꾸지 않는다.
    - 인용 안에서 요약·의역·번역하지 않고, 설명이나 `(중략)` 을 끼워 넣지 않는다. 길어도 전부 옮긴다.
    - 원문이 여러 줄이면 줄마다 앞에 `> ` 를 붙인다.
    - 외국어 원문도 번역하지 않고 원문 그대로 둔다. 내용 이해는 요약·핵심 구성에서 한국어로 한다.
    - 원문을 구하지 못했으면 인용(`>`)을 쓰지 말고 그 자리에 `➕ 추가 권장` 한 줄만 둔다. 요약이나 기억으로 채우지 않는다.
    - 청구항 번호는 받은 그대로 쓴다. 사용자가 다른 항을 지정하지 않으면 청구항 1을 쓴다.
- 특허번호·출원인·날짜·법적 상태는 자료에 나온 그대로 쓴다. 자료에 없으면 `➕ 추가 권장`.
- 국가는 특허번호 앞의 국가 코드로 정한다. 목록에 없는 코드면 기타.
- 공개일과 등록일을 둘 다 알면 속성에 넣지 않은 쪽은 `## 메모` 에 적는다.
- 비교 표
    - 우리 발명 칸은 사용자가 준 내용으로만 채운다.
    - 한쪽에만 있는 구성은 다른 쪽 칸에 `없음` 이라고 쓴다.
    - 판단이 애매한 칸은 `➕ 추가 권장` 로 두고 ③ 확인할 것에 무엇을 확인할지 적는다.
    - 칸 안에서 줄을 바꾸지 않고, 칸 안의 `|` 는 `/` 로 바꿔 쓴다.
- 차별화·회피 포인트
    - 사용자가 따로 말하지 않으면 비교 표 "차이" 칸의 내용만 묶어 정리한다(새 주장을 보태지 않는다).
    - "차이" 칸이 모두 같음이면 "비교 표에서 차이가 확인되지 않음" 한 줄만 쓴다.
    - 침해 여부·회피 가능 여부 같은 법적 판단을 단정하지 않는다(변리사 몫). 사용자가 한 판단은 쓴 그대로 옮긴다.
- 관련도 제안 기준: 상 — 핵심 구성 대부분이 겹침 / 중 — 일부 구성이 겹침 / 하 — 기술 분야만 같음.
- 특허 여러 건을 한 번에 받으면 건마다 따로 출력한다(1건 = 페이지 1개).
